2. Purpose

This app is designed to help students manage their own schedules and those of their friends. It supports personal schedules, schedule sharing, and collaboration.

The client wanted an intuitive scheduling tool where students could easily view their own and each other’s schedules on both mobile and desktop, with a simple interface and clear visual structure.

To meet these needs, SyncSpace includes login-based personal accounts, group calendar sharing, a day view for checking specific dates, and a feature that calculates common free time across multiple users’ schedules.

3. Data Description

USERS

  • user_id — INT — Primary Key
  • username — VARCHAR(50)
  • email — VARCHAR(100)
  • password_hash — VARCHAR(255)
  • created_at — DATETIME

GROUPS

  • group_id — INT — Primary Key
  • group_name — VARCHAR(100)
  • description — TEXT
  • created_by — INT
  • created_at — DATETIME

GROUP_MEMBERS

  • membership_id — INT — Primary Key
  • group_id — INT
  • user_id — INT
  • role — VARCHAR(20)
  • joined_at — DATETIME

EVENTS

  • event_id — INT — Primary Key
  • title — VARCHAR(100)
  • description — TEXT
  • start_time — DATETIME
  • end_time — DATETIME
  • created_by — INT
  • owner_user_id — INT — nullable
  • owner_group_id — INT — nullable
  • location — VARCHAR(150)
  • is_all_day — BOOLEAN
  • created_at — DATETIME
  • updated_at — DATETIME
  • anonymous — BOOLEAN
  • importance — INT

RECURRING_EVENT

  • recurring_id — INT — Primary Key
  • event_id — INT
  • repeat_type — VARCHAR(20)
  • interval_value — INT
  • days_of_week — VARCHAR(20) — nullable
  • end_date — DATETIME — nullable
  • occurrence_count — INT — nullable

EVENT_EXCEPTIONS

  • exception_id — INT — Primary Key
  • recurring_id — INT
  • original_date — DATETIME
  • is_cancelled — BOOLEAN
  • new_start_time — DATETIME — nullable
  • new_end_time — DATETIME — nullable
  • new_title — VARCHAR(100) — nullable
  • new_description — TEXT — nullable
